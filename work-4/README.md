# 作业 4：使用 SVM 做 Spambase 垃圾邮件分类

## 数据集

使用课件“真实数据分析案例”中的 **Spambase** 数据集：

- 来源：[UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/94/spambase)
- 样本：4601 封邮件
- 特征：57 个，包括 48 个词语频率、6 个特殊字符频率和 3 个大写字母游程统计量
- 标签：`1` 为垃圾邮件，`0` 为正常邮件

## 实验方法

1. 按 8:2 分层划分训练集和测试集，随机种子为 42。
2. 使用 `StandardScaler` 对特征做标准化。
3. 使用线性核 SVM，参数取课件示例中的 `C=1`。
4. 在测试集上计算准确率、F1 和混淆矩阵。

标准化和 SVM 放在同一个 Pipeline 中，避免测试集信息泄漏。

## 运行

```bash
python work-4/__init__.py
```

如果 `data/spambase.data` 不存在，脚本会自动从 UCI 下载。

## 实验结果

- 训练集：3680 封，测试集：921 封
- 准确率：**92.94%**
- F1：**90.93%**

混淆矩阵（行表示真实类别，列表示预测类别）：

| 实际 \ 预测 | 正常邮件 | 垃圾邮件 |
| --- | ---: | ---: |
| 正常邮件 | 530 | 28 |
| 垃圾邮件 | 37 | 326 |

垃圾邮件的精确率为 92.09%，召回率为 89.81%。在 363 封测试集垃圾邮件中，模型正确识别了 326 封。结果与课件中线性 SVM 在 Spambase 上约 92% 的准确率相近。

线性 SVM 的优点是训练速度较快，且适合 Spambase 这种特征维度较高、线性可分性较好的文本分类任务。
